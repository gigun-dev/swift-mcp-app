SwiftUI 実装メモ(ChatHistorySidebar.swift 置き換えの要点)
  1. 骨格は現状維持: 表示専用・store 直読み・onSelect/onNewChat/onClose の コールバック契約・reload/検索フィルタは不変。日付グループ関数 (groupedSummaries)は削除(平坦リスト化)。loadIndex() が updatedAt 降順を 保証するのでソートも不要。
  2. List は .plain のまま edge-to-edge: セクション無しの単一 ForEach。 先頭に「最近の項目」ラベル(Text(.caption).fontWeight(.semibold) .foregroundStyle(.tertiary))を listRowSeparator(.hidden) 付きの行として置く。 区切りは List 既定 separator を .listRowSeparatorTint(...) で paper トーンのヘアライン色に。行のゆとりは .listRowInsets(EdgeInsets(top:14, leading:16, bottom:14, trailing:16))。
  3. 行レイアウト: HStack { VStack(alignment:.leading, spacing:3) { title(.body.weight(.semibold), lineLimit(1)) / HStack(spacing:7){ 相対時刻(.caption, .secondary) + (複数サーバー時のみ)chip } } + Spacer + Image(systemName:"chevron.right")(.caption2, .tertiary) }。 preview は表示しない(DTO からは消さない — 検索フィルタでは引き続き preview も 部分一致対象。表示だけやめる)。
  4. 相対時刻ヘルパ: metaLine() を RelativeDateTimeFormatter (dateTimeStyle = .named で「昨日」「たった今」が出る・locale 追従で 「6分前/2時間前/13日前」)に置き換え。formatter は static let でキャッシュ (生成コストが高い)。serverShortName() は chip 用に残す。
  5. サーバー chip の出し分け: 表示条件 = Set(summaries.map { serverShortName($0.serverURL) }).count > 1 を computed で持ち、真のときだけ**全行に** chip を出す(行ごとの出し分けだと 一部だけ chip 無しが欠落に見えるため一覧単位で切り替える)。chip = Text(.caption2.weight(.semibold)).padding(.horizontal,7).padding(.vertical,1.5) .background(Capsule().fill(Color("PaperSubtle"))).foregroundStyle(.secondary)。
  6. アクティブ行 = 角丸ピル塗り: .listRowBackground(isActive ? AnyView(RoundedRectangle(cornerRadius:14) .fill(Color("PillActive")).padding(.horizontal,8).padding(.vertical,3)) : nil) — 背景 View は行サイズに引き伸ばされるので padding で内側に寄せるとピルになる。 accent 色は使わない(手本準拠)。active 行は .listRowSeparator(.hidden) でヘアライン衝突を回避。
  7. フローティング黒ピル: List に .overlay(alignment:.bottom) + 下 padding 20 で重ねる(safeAreaInset だとリスト末尾がピルの上で止まり 「後ろを流れる」抜け感が出ない)。List 末尾に Color.clear.frame(height:96).listRowSeparator(.hidden) のフッタ行で逃げを作る。 ピル = Button { onNewChat(); onClose() } label: { Label("新規チャット", systemImage:"plus") } .fontWeight(.semibold).padding(.horizontal,22).padding(.vertical,13) .background(Capsule().fill(Color("FabBG"))).foregroundStyle(Color("FabFG")) .shadow(color:.black.opacity(0.22), radius:10, y:6)。 FabBG/FabFG は light=黒/白・dark=白/黒 の Assets ペア。
  8. パレット: paper トーンは semantic color で出せないため Assets に自前定義: Paper(#faf9f5 / #211f1c)・PaperSubtle(#f1efe9 / #2c2a26)・ PillActive(#e9e6dd / #33312b)・FabBG/FabFG。drawer 背景 = Color("Paper")、List は .scrollContentBackground(.hidden) + 同色 background。drawer chrome は前版のまま(親 ChatHomeView 側): UnevenRoundedRectangle(topTrailingRadius:20, bottomTrailingRadius:20) で clip + shadow(black 18%, radius 16, x:8) + 幅 min(width*0.82, 320) + 暗幕 black.opacity(0.3)。
  9. 検索・その他: 検索は上部据え置き(手本の最下部はピルと競合するため逸脱)。 TextField 箱は PaperSubtle 塗り・cornerRadius 12。swipeActions・ 空状態分岐(検索0件/履歴ゼロ)は既存踏襲。行は Button のままで VoiceOver 既定 対応。フォントはセマンティック(body/caption)で Dynamic Type 追従。 相対時刻+chip は .accessibilityElement(children:.combine)。
ボツ案メモ: (a) 初版の insetGrouped カード+左3pxアクセントバー+preview 表示 — Claude iOS 実機スクショの所見を受けて撤回。高級感の源泉を「カード枠」と誤診していた。 (b) 日付セクション見出し — 相対時刻と二重。履歴が数百件規模に育ったら復活を再検討 (可逆)。(c) 検索の最下部配置(手本準拠)— フローティングピルと競合。 (d) preview のデータ削除 — 表示はやめるが検索対象としては残す。
